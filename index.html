Fundamentos visuales

¿Qué es un JOIN?

Un JOIN combina filas de dos fuentes según una condición de relación. Puede conservar solo coincidencias o también registros sin pareja. En Oracle SQL, la condición suele expresarse mediante ON.

¿Qué es?

Una relación entre filas

Por ejemplo, clientes.cliente_id = pedidos.cliente_id. La clave relaciona una persona con sus pedidos.

¿Cómo funciona?

Empareja y conserva

Oracle evalúa la condición lógica de unión; el tipo de JOIN determina qué ocurre con las filas que no tienen coincidencia.

¿Para qué sirve?

Responder preguntas

Ventas por cliente, empleados sin asignación, conciliación de fuentes, reportes y análisis de datos relacionados.

Perspectiva del optimizador
Infografía 02 · ¿Cómo ejecuta Oracle un JOIN?
El JOIN lógico describe el resultado deseado. El optimizador elige un método físico en función de estadísticas, predicados, cardinalidad y costos estimados.


↻ Nested Loops
Para cada fila externa, busca coincidencias en la fuente interna. Puede funcionar muy bien con pocas filas externas y acceso eficiente mediante índice.
▦ Hash Join
Construye una tabla hash sobre una entrada y busca coincidencias con la otra. Suele ser útil para conjuntos grandes y uniones por igualdad.
≡ Sort Merge Join
Ordena o aprovecha entradas ordenadas y recorre ambas. Puede ser apropiado en determinadas condiciones de unión y ordenación.


Consulta para inspeccionar el plan estimado
EXPLAIN PLAN FOR
SELECT c.nombre, p.pedido_id
FROM clientes_lab c
JOIN pedidos_lab p ON p.cliente_id = c.cliente_id;

SELECT * FROM TABLE(DBMS_XPLAN.DISPLAY);
